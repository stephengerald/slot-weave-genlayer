# SlotWeave architecture and originality boundary

A multi-member preference ledger and deterministic tally with rotating tie-breaks and owner cancellation.

The eight-contract portfolio was cross-checked pairwise for primary input, consensus task, stored state, state transitions, and output. This contract does not share another portfolio member's domain workflow or state machine. Shared input modalities or standard GenLayer authorization are not the architecture.

Scope limit: Only invited wallet submissions count. The contract does not check external calendars or promise attendance.
